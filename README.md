# 星跃远征 · 十座王庭 v11

本地可玩的原创哥特像素动作远征。新版已接入 10 大关 × 5 小关，共 50 关，关底有 10 位不同 Boss。每 10 小关更换一次地貌，延续余烬行者、多帧战斗、精英、支路与铭刻系统。公开游玩：[直接开始远征](https://le3334515-tech.github.io/starhop-expedition/?v=11.0)。无需安装或登录，电脑和手机均可打开。

## v11 五十关远征

打开 `http://localhost:4173` 后点击「开启50关远征」。每关清理主路敌人开启星门；第 5、10……50 小关为 Boss 战，击败后走入星门继续。章节间补满生命。每关入口自动存档，重开页面或死亡后点击「继续远征」回到本关入口；存档保留当时的武器、铭刻、等级与资源，不保存战斗中的瞬间。

「章节与首领」可直接试玩十个章节，附带该章节基础配装，保留原连续远征存档。章节试玩不算完整连续通关。旧版「开启试炼」仍可单独试玩双支路短图。

每个章节依次为门廊、回环、断桥、封锁、王座五类布局，通过种子、章节变体、敌人组合和主题材质生成。高台藏珍为可选路线，守卫不阻止主路开门。普通补给匣奖励 6 星币和 1 颗心，避免每关重复乘伤害。锻火强化需 10 星币，后期属性达到上限后仍有可选择的淬火或补给。

十位 Boss 使用各自的招式轮转，半血进入二阶段。刀枪与弹幕可精准格挡；地波、地刺与跃击要跳跃或闪避，先显示落点。召唤最多两名随从。Boss 死亡后先解锁星门，只有最终关出口才结束连续远征。

## 启动与操作

安装 Node.js 后双击 `启动游戏.cmd`，或运行 `npm start`，打开 http://localhost:4173。运行游戏无需安装开发依赖。请通过 HTTP 启动，直接打开 HTML 会被浏览器拦截模块加载。

手机真机试玩：双击 `手机试玩.cmd`，保持窗口开启，手机与电脑连接同一 Wi-Fi，打开窗口列出的 Wi-Fi 地址（端口 4174）。默认 `npm start` 仍只在本机监听。

- A / D 移动，空格跳跃和二段跳，J 攻击，Shift 闪避，F 格挡，E 互动，1 / 2 / 3 切换武器，Q 觉醒，Esc 暂停。
- 手机使用速度摇杆和多指动作键。大厅「按键设置」或暂停「按键布局」可改键、拖动摇杆和动作键，并保存位置、大小和透明度。

## 试玩路线

试招小径与苔甲石傀 → 腐化木灵与盾卫 → 检查点与裂翼妖蝠 → 精英灰烬监守 → 归途星门。

沿路木箱可用刀、法杖或飞轮击碎，掉落星币；部分木箱必掉回血药瓶。满血时药瓶会留在地图上。拾取有逐帧消散动画。靠近安全的检查点会燃起烛火，首次恢复 1 颗心及全部精力，记录落坑后的返回位置；重复经过不会重复回血。

树桩预警后朝锁定位置发射可格挡、反弹的种子；蝙蝠悬停后朝锁定位置俯冲，结束后回到悬停高度；岩石怪蓄势后冲撞，有明显收招。新素材采用冷蓝修院、暗红残旗与烛火高光，敌人改为成人比例的枯木、骨翼、石甲及锈甲轮廓。

在约三分之一处可跳上左侧木台，连续攀上高台进入藏珍支路。击败高台木灵后，靠近金色宝匣按 E 或手机互动键，获得全武器伤害 +35%、恢复 1 颗心、1 层护盾和 12 星币。宝匣只可领取一次。支路守卫不计入主路星门解锁条件，可以跳过支路完成试玩。

精英区后还可跳上 2460 处木台，前往圣物残桥，击败上层守卫后开匣选择一次铭刻。第二处烛火旁的锻火台可花费 10 星币再选择一次强化。

## 战斗规则

- 每次攻击有前摇、有效攻击和收招阶段。仅有效阶段进行判定，同一攻击对同一目标只命中一次。动画、刀光与动作进度对齐。
- 轻击收招可接闪避，重斩需要完成关键动作后才能取消；可提前缓存下一击、闪避和跳跃。取消会关闭旧判定。
- 精力上限 100，短刃 / 法杖 / 飞轮起手分别消耗 5 / 4 / 7，法杖完整蓄力额外消耗 5。闪避消耗 20，普通格挡每次消耗 28。收招与空闲时可恢复精力，普通攻击不会像旧版一样迅速打空。
- 闪避持续 0.18 秒，基础冷却 0.65 秒，对每个目标造成一次闪身伤害；后半段可接强化追击。
- 短刃：轻、轻、重三段，重斩破架势，绕后命中有背击奖励，精准反击和闪身追击可强化攻击。
- 法杖：点按快速发射并叠灼印，第三次点按命中或蓄力命中会引爆；打已有灼印的目标回报更高，爆炸可波及近邻。长按约半秒完成蓄力，具备小幅辅助瞄准。
- 飞轮：有在场数量上限，去回程各可命中一次；同一目标去回程都命中时强化回程。再次按攻击可提前召回，接回恢复 8 精力并强化下一次攻击。多弹强化可提高数量上限。
- 普通怪不再通过被动接触扣血。巡林客近战压迫，弩手预警后朝锁定方向射击，盾卫格挡正面轻击，精英使用延迟二连。
- 普通遭遇同时准备 / 执行攻击的敌人数不超过两个。架势击破产生失衡窗口；精准格挡只作用于本次攻击的来源，远程攻击可反弹。
- 起手 0.16 秒内正面接招可精准格挡，普通格挡消耗精力。背后、地形与明确不可格挡的攻击不能用格挡解决。升级恢复 1 颗心和全部精力，精英必掉回血。

## 代码与验证

- `assets/combat-actions.js`：原创武器动作与怪物参数。
- `assets/combat-runtime.js`：动作执行、取消、统一受击、武器释放与支路奖励。
- `assets/monster-ai.js`：预警、出招、收招、失衡和遭遇战并发限制。
- `assets/trial-map.js`：试玩主路、可选高台、精英与出口。
- `assets/forest-runtime.js` / `forest-art.js`：可破坏木箱、拾取、检查点与森林素材动画。
- `assets/game-core.js`：原有基础模拟、角色移动、升级和效果支持。
- `assets/game.js` / `souls-presentation.js`：界面、动画同步、预警与场景标记。

`npm install` 后运行 `npm test`，需要 Chrome。测试覆盖有效攻击阶段、取消与缓存、伤害来源、格挡、武器差异、精英二连、奖励可选与防重复、实际跳跃穿越支路、多武器多种子完整主路通关，以及手机多指、横竖屏、键位与布局保存。`node scripts/playtest-trial.mjs` 可单独查看三武器正常输入模拟通关结果，未使用血量覆盖、强制击杀或传送。

这是自动验证与浏览器试玩，仍需用户在手机真机上评估主观手感。试炼规则独立，成绩仅保存在本地，不自动上传旧版排行榜。

八境旧生成器保留在引擎中，`start({ mode: 'expedition', ... })` 可供后续迁移；这轮平衡与试玩验证集中在短程试炼。之前的本地像素绘制改动仍保存在 Git stash 检查点中。
