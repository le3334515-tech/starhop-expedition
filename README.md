# 星跃远征 · STARHOP

[立即游玩 / Play now](https://le3334515-tech.github.io/starhop-expedition/)

原创像素横版动作肉鸽：四幕远征、三武器、强化羁绊、星陨觉醒、三连重斩与三阶段 Boss。
手机确认开局自动横屏，触控按键支持拖动位置、大小和透明度设置。

在游戏内发起好友战书，可以挑战相同地图与规则。通关后自动提交真实成绩；共享排行榜按四种规则分别展示最快前十，同一旅人只保留最佳用时。
新纪录通过实时消息同步，历史前十由 GitHub Actions 每小时自动归档。初始为空榜，没有填充虚构成绩。榜单数据通过 raw.githubusercontent.com 读取。

本仓库托管可直接运行的静态游戏构建和排行榜归档脚本，不需要安装或登录。
所有图像由游戏代码绘制，音乐与音效由 Web Audio 合成，AI 辅助制作。
