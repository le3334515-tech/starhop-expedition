# 星跃远征 v4.2

基于用户提供的《星跃远征 v4.1》制作的改进版，保留像素武侠风格、角色与场景素材、八幕远征和三种武器。

公共游玩地址：[开始远征](https://le3334515-tech.github.io/starhop-expedition/classic/)。电脑和手机直接打开，无需安装。此版本部署在独立的 `classic/` 目录，已有根站和 `jade/` 版本保留。

## 本次改进

- 增加八幕剧情，让每幕目标与最终 Boss 有连续叙事。
- 丰富地形与补给路线，修正平台衔接和角色起落问题。
- 改善跳跃手感，加入闪避伤害、升级回血及地图回血掉落。
- 强化短刃、萤火法杖、回声飞轮各自的战斗反馈。
- 增加 Boss 格挡与精准格挡。
- 手机采用速度摇杆，动作键支持多指操作；键盘可自定义绑定，触控可调整布局。

## 操作

| 动作 | 默认按键 |
| --- | --- |
| 移动 | A / D 或 ← / → |
| 跳跃、二段跳 | 空格 / K；长按跳得更高 |
| 攻击 | J / X |
| 闪避 | Shift / L |
| 格挡 | F |
| 切换武器 | 1 / 2 / 3 |
| 星陨觉醒 | Q |
| 进入星门 | E |
| 暂停、继续 | ESC / P |

手机用左侧摇杆移动、右侧按键行动。按键设置与布局保存在当前浏览器。每次开始前可查看操作指南，暂停后可调整布局。

## 本地运行与离线版

需要 Node.js 20.19+ 或 22.12+。依赖版本由 `package-lock.json` 固定。

```powershell
npm ci
npm run dev
npm test
npm run build
npm run package
```

`dist/` 为网站部署文件；`delivery/星跃远征.html` 为素材内嵌的离线单文件，双击即可游玩。共享成绩查看、同步与提交需要联网，游戏本体不需要联网。

本版公共链接为 `https://le3334515-tech.github.io/starhop-expedition/classic/`。好友挑战使用当前页面生成链接；从离线版分享时，把 HTML 文件与挑战码一起发送。

v4.2 的共享成绩使用独立榜单，不与原 v4.1 的八幕用时混排。原八幕纪录作为历史读取，原四幕历史数据和根站归档文件保留。昵称身份沿用，待上传队列与本版成绩缓存独立保存。
