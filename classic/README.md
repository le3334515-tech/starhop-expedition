# 星跃远征 v4.8.1

基于用户提供的《星跃远征 v4.1》制作的改进版，保留像素武侠风格、角色与场景素材、八幕远征和三种武器。

公共游玩地址：[开始远征](https://le3334515-tech.github.io/starhop-expedition/classic/?v=4.8.1)。电脑和手机直接打开，无需安装。此版本部署在独立的 `classic/` 目录，已有根站和 `jade/` 版本保留。

下载：[离线版 v4.8.1](https://le3334515-tech.github.io/starhop-expedition/classic/offline-v4.8.1.zip) · [源码 v4.8.1](https://le3334515-tech.github.io/starhop-expedition/classic/source-v4.8.1.zip) · [竞速后端源码](https://le3334515-tech.github.io/starhop-expedition/classic/race-relay-v4.5.zip)。

## v4.8.1 手机封面

手机版把主视觉、好友入口和行牒分开陈列；行牒显示首站，点开可查看八境顺序。

## v4.8 天烬降临
从第二幕起逐步提高守卫的攻击节奏。沉钟与炉火可制敌，法杖的灼印可由回程飞轮引爆。玄烬魔君二形态降到半血时会再度变身，战斗续用剩余生命。最终阶段的专属攻势由《天烬终曲》伴奏，主角发动星陨觉醒时会展开玉金符阵。

## v4.7 余烬破封
普通远征、守卫迎战与玄烬魔君各有一首原创配乐。守卫破封时，战鼓收声，长杖聚焰，铜锣落下时金面法相显现、双幡展开；第二形态沿用原金面、兜帽与焰杖，并在连冲收招时留下延迟爆发的杖印。音乐与所有动作已嵌入离线版。

## v4.6.1 双人连接修复

点「双人竞速」后可复制好友直连邀请。房主在竞速期间保持游戏页面打开。浏览器未开放直连时，同一邀请会尝试加密 HTTPS 线路。遇到两台设备无法直连时，房主可在等待页点「改用服务器建房」，再分享新邀请。

## v4.6 手机联机与七境机关

- 手机大厅可直接换路线、发起双人竞速和接收战书。邀请保存在网址参数中，也可复制房间码入场。
- 手机弹窗随画面旋转，切到后台可从暂停页继续。
- 七个普通关各有专属机关。青竹、朱灯、逆风、钟波、涌泉、炉火和星闸各有启动预兆。泉眼喷发时可以借力起跳。
- 每境增添一种地方守卫。新增踏雪生梅、金钟回响、拾玉还风三枚修行印。

## v4.5 动作、换序与双人竞速

- 法杖和飞轮使用各自利落的施法、甩投与收势动作，清理远程角色残留剑影；短刃保留原三连斩与像素风格。
- 七个普通关随本次种子真实换序，每境只出现一次，Boss固定第八关。行牒、地图册、目标与剧情跟随实际关卡顺序；同一挑战种子仍复现相同路线。
- 强化面板展开640毫秒后才可选择；只接受新的一次鼠标点击或触屏点按，键盘和手柄不会选中强化，避免战斗输入误选。
- 新增双人在线竞速：创建房间并分享邀请链接，双方准备后同步倒数5秒，各自完成相同八境路线。可看到对方的半透明影像和关卡进度，影像不参与碰撞。
- 竞速计时包含强化选择和暂停，完成后同步双方成绩。单人远征、同图挑战与原有排行榜继续保留；在线竞速需要联网。

## v4.4.1 武器动作修正

- 法杖采用抬杖、出掌施法与回弹收势，飞轮采用独立甩投与收手动作。
- 远程武器不再复用拔刀攻击帧，并清理角色原动画中的残留剑影；待机、跑动和空中动作与当前武器对应。
- 短刃继续使用原有三连斩动作。角色、配色与像素风格保留，伤害、碰撞判定和出手时机不变。

## v4.4 战斗更新

- 格挡在键盘、触屏按下及手柄边沿同步送入仿真；可打断冲刺，不再等待顿帧结束。按钮内部显示真实恢复与生效状态。
- 七个普通关采用不同地区敌人组合和招式，角色、背景、怪物继续保持统一的像素武侠风格。
- 2号武器强化追踪贯穿、焰爆与灼烧；3号武器强化双轮往返和回锋破弹，分别有明确命中特效。
- 三种武器在修为LV.4、LV.7时同步进阶，武器栏显示Ⅰ、Ⅱ、Ⅲ阶，进阶时给出提示。
- Boss第一形态为余烬守卫；击败后变身为满血的玄烬魔君，黑化后增加地裂墨柱、墨雨等招式，第二形态血量继续降低后进入狂暴。
- 保留此前一跳高度、适度二段跳、天仪中枢背景修复、手机按键避碰与玉简强化界面。

| 兵器 | 一阶 | LV.4 二阶 | LV.7 三阶 |
| --- | --- | --- | --- |
| 星陨短刃 | 三连重斩 | 斩击范围+10，伤害+12% | 范围合计+20，伤害+24% |
| 萤火法杖 | 追踪贯穿、焰爆灼烧，每第三击蓄能 | 增加一道星焰 | 普通弹贯穿数进一步增加 |
| 回声飞轮 | 双轮往返，回锋增伤45% | 三轮齐出 | 接触敌方飞弹时将其击碎；地裂不受此影响 |

## v4.3.1 修正

- 一段跳维持轻点约 150、长按约 202 逻辑像素；二段跳改为短促补高，满按额外约 75，两跳合计约 277。过早二跳保留原来更强的上升速度，不能三段连跳。
- 修正天仪中枢远景中的矩形硬边与海面色带，让建筑和水面融入原有景色。
- 手机格挡、攻击和武器 HUD 避免互相遮挡；放大按键和读取旧布局时也会检查碰撞。

## 核心玩法与强化

- 提高轻点跳跃下限：经典规则下，极短轻点约升高 150、长按约 202 逻辑像素，保留二段跳。
- 升级界面改为青玉行牒、符印和立绘式三选一，展示每项强化前后的数值。
- 九种强化提高收益，并各自呈现随本局生效的特效；HUD 显示已习得的符印和叠加层数。
- 手机移除 E 互动键；主路清理完成后，直接走入星门即可过关。

| 强化 | 效果 |
| --- | --- |
| 星刃淬火 | 每层伤害增加 65% 基础值，朱金余焰随斩击呈现 |
| 疾风节拍 | 每层攻速 ×1.35，最高 2.8 倍，带出疾风残影 |
| 不灭星心 | 生命上限 +2，立即回满生命，呈现气血暖辉 |
| 追风旅靴 | 每层移速 ×1.18，最高 460；缩短闪避冷却，附带伤敌风刃 |
| 双星共鸣 | 每层额外飞弹 +1，最多额外 3 枚；近战也可附带星光弹 |
| 月光守护 | 立即获得 3 层护盾，进入新关补 1 层；护盾消耗时同步改变月环 |
| 生命余烬 | 击杀必定回复 1 颗心，呈现红纹与回流星火 |
| 星尘引力 | 每层吸取半径 +220，经验与星币汇入聚灵阵 |
| 闪耀口袋 | 每层让每次拾币额外获得 2 金币与 3 星能，呈现金色星屑 |

强化持续到本局结束，重开后重新成长；除星心直接回满外，选择强化时通常恢复 1 颗心。

## 延续的内容

- 增加八幕剧情，让每幕目标与最终 Boss 有连续叙事。
- 丰富地形与补给路线，修正平台衔接和角色起落问题。
- 改善跳跃手感，加入闪避伤害、升级回血及地图回血掉落。
- 强化短刃、萤火法杖、回声飞轮各自的战斗反馈。
- 增加 Boss 格挡与精准格挡。
- 手机采用速度摇杆，动作键支持多指操作；键盘可自定义绑定，触控可调整布局。

## 操作

| 动作 | 默认按键 |
| --- | --- |
| 移动 | A / D 或 ← / → |
| 跳跃、二段跳 | 空格 / K；长按跳得更高 |
| 攻击 | J / X |
| 闪避 | Shift / L |
| 格挡 | F |
| 切换武器 | 1 / 2 / 3 |
| 星陨觉醒 | Q |
| 进入星门 | 清理主路后走入星门；电脑也可按 E |
| 暂停、继续 | ESC / P |

手机用左侧摇杆移动、右侧按键行动，不再显示 E 按钮。按键设置与布局保存在当前浏览器。每次开始前可查看操作指南，暂停后可调整布局。

## 本地运行与离线版

需要 Node.js 20.19+ 或 22.12+。依赖版本由 `package-lock.json` 固定。

```powershell
npm ci
npm run dev
npm test
npm run build
npm run package
```

`dist/` 为网站部署文件；`delivery/星跃远征.html` 为素材内嵌的离线单文件，双击即可游玩。共享成绩查看、同步与提交和双人在线竞速需要联网，单人游戏本体不需要联网。

本版公共链接为 `https://le3334515-tech.github.io/starhop-expedition/classic/?v=4.8.1`。好友挑战使用当前页面生成链接；从离线版分享时，把 HTML 文件与挑战码一起发送。

v4.4 沿用经典版既有的共享榜单、缓存命名空间和玩家身份，不清空已有成绩。原 v4.1 八幕纪录与原四幕纪录仍独立显示，根站归档文件保留。
