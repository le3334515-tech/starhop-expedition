# 星跃远征 v5.2.2 · 玄阙同征

基于用户提供的《星跃远征 v4.1》制作的像素武侠动作游戏，包含八境单人远征、双人在线竞速和十一境合作远征。

## v5.2.2 战斗难度

普通守卫、飞行怪和合作增援的出生血量均翻倍。合作仍按队伍人数加成，两位首领的第一形态与第二形态血量提高约 25%。二阶段降到半血时进入最终形态。陆照月的第二把兵器霜枝杖换成紫赤漆枝与银玉月牙的原创造型。

合作客人刷新同一个标签页后可恢复原席位、关卡、装备和强化，房主需要继续留在游戏中。双人竞速按同一套难度规则配对。服务器线路重赛后只接收当前轮次的成绩和幽影进度。

总排行榜在每套规则下记录每位玩家最快的成绩，同时显示使用的英雄与通关时间。英雄排行榜可切换六位旅人，同一玩家使用不同英雄的最佳成绩分别保留。旧成绩缺少英雄名时按原版主角裴行舟归类。

怀岳的镇岳拳与伏虎铁拳伤害分别提高 35% 和 45%，回山佛珠的伤害提高约 23%。贴身连拳能在短反击窗口打出更高伤害。

沈霄、陆照月、青翎、闻朔与怀岳各有专属闪避拖尾与完美闪避印记，裴行舟使用原版闪避。

## 旅人与兵器

单人、竞速和合作的选角第一格都是红笠主角裴行舟。

单人可从大厅或开局指南进入「选择旅人」，选择角色及起手兵器。双人竞速在准备前各自选角，同一角色也能同场竞速。开局后能看到好友的半透明角色和他正在使用的武器。红笠主角裴行舟沿用原作的短刃、法杖和飞轮。

| --- | --- | --- | --- | --- |
| 沈霄 | 星陨短刃 | 柳叶软剑 | 归燕镖 | 万刃归鞘，飞剑从两侧交错归阵 |
| 陆照月 | 萤火法杖 | 霜枝杖 | 照月镜 | 月蚀照庭，月相法盘伴随星火 |
| 青翎 | 青羽折扇 | 翠翎针 | 绫罗团扇 | 翠羽天幕，玉色扇骨在身后展开 |
| 闻朔 | 金霆长枪 | 芦影标枪 | 断岳戟 | 孤城列戟，枪影在头顶列阵 |
| 裴行舟（原版主角） | 星陨短刃 | 萤火法杖 | 回声飞轮 | 星陨觉醒，原版玉金符阵 |
| 怀岳 | 镇岳拳 | 伏虎铁拳 | 回山佛珠 | 山门金身，拳印与山影合拢 |

战斗中按 1 / 2 / 3，或点武器栏的对应图标切换。切换后第一击带有追击加成。三件兵器随本局修为一同进阶。角色和起手兵器会一并记入战书和单人通关纪录。

五位旅人的普通命中、重击和回锋会在敌人身上留下不同的痕迹，分别使用剑鸣、月杖、扇风、枪戟和拳劲的命中声。快招的顿点短，长戟与铁拳的收招更重。同一招扫中多个守卫时共用一个顿点。

五位旅人各有一招换武连携。用 2 号兵器命中后，在 2.4 秒内用 3 号追击同一目标即可触发。沈霄的归燕镖回程增伤 35%，陆照月用照月镜回复 4 点星能，青翎用团扇震停小怪 0.5 秒，闻朔用重戟额外削去首领 6 点护甲，怀岳用佛珠回程缩短 0.4 秒闪避冷却。裴行舟继续使用法杖留灼印、飞轮回程引爆的原版连携。

修行池共有 18 项。新增的错金换锋、三星照命、惊鸿留影、玉关照胆、碎玉鸣泉和穿云落印分别在换武追击、第三击、完美闪避、精准格挡、拾心和二段跳落地时生效。触发时能看到相应纹样。合作中每人单独选择与叠加强化。

## 四人合作远征

在大厅点「四人合作远征」，发邀请链接给好友。从六位旅人中各选一人，队内角色各不相同。全员准备后由房主点「全队出发」。合作中每人独立换武器和选强化，队友倒地时可以走近援救。挑战期间房主应保持游戏页在前台。

人数越多，敌方生命、攻击频率和首领护甲越高，部分关卡还会增加守卫。通过第八关余烬神殿后，进入有高台炉火的「赤铸悬城」、结合逆风与星闸的「断月星桥」，最后在「玄阙王庭」迎战新的三阶段首领玄阙镇星王。镇星王蓄势劈斩、连续冲锋，最后一变身落下交错剑柱。新增关卡播放《炉桥行》，首领每阶段分别使用《镇星誓》《开锋》《王刃裁天》，两次变身分别使用《熔甲》和《加冕》。

队伍结算显示成员、通过关数与用时。单人榜单继续记录八境单人远征成绩。

## v4.9.1 平台机关与法杖

普通关的部分机关落在高台，平台两端留有起跳和落脚空间。萤火法杖的直接火弹和爆炸余波对 Boss 的生命伤害降低 9%。

## v4.9 战斗与特效

手机版恢复 v4.8 的封面构图与行牒位置。普通关的守卫随进度加快追击和出招，Boss 的护甲与连段随形态加强。最终形态连冲会在玩家原先的位置留下延迟爆发的杖印。星陨觉醒时，玉剑、残影和符箓在爆发点聚合，短刃、法杖与飞轮各有对应的觉醒光效。

## v4.8 天烬降临
从第二幕起逐步提高守卫的攻击节奏。沉钟与炉火可制敌，法杖的灼印可由回程飞轮引爆。玄烬魔君二形态降到半血时会再度变身，战斗续用剩余生命。最终阶段的专属攻势由《天烬终曲》伴奏，主角发动星陨觉醒时会展开玉金符阵。

## v4.7 余烬破封
普通远征、守卫迎战与玄烬魔君各有一首原创配乐。守卫破封时，战鼓收声，长杖聚焰，铜锣落下时金面法相显现、双幡展开；第二形态沿用原金面、兜帽与焰杖，并在连冲收招时留下延迟爆发的杖印。音乐与所有动作已嵌入离线版。

## v4.6.1 双人连接修复

点「双人竞速」后可复制好友直连邀请。房主在竞速期间保持游戏页面打开。浏览器未开放直连时，同一邀请会尝试加密 HTTPS 线路。遇到两台设备无法直连时，房主可在等待页点「改用服务器建房」，再分享新邀请。

## v4.6 手机联机与七境机关

- 手机大厅可直接换路线、发起双人竞速和接收战书。邀请保存在网址参数中，也可复制房间码入场。
- 手机弹窗随画面旋转，切到后台可从暂停页继续。
- 七个普通关各有专属机关。青竹、朱灯、逆风、钟波、涌泉、炉火和星闸各有启动预兆。泉眼喷发时可以借力起跳。
- 每境增添一种地方守卫。新增踏雪生梅、金钟回响、拾玉还风三枚修行印。

## v4.5 动作、换序与双人竞速

- 法杖和飞轮使用各自利落的施法、甩投与收势动作，清理远程角色残留剑影；短刃保留原三连斩与像素风格。
- 七个普通关随本次种子真实换序，每境只出现一次，Boss固定第八关。行牒、地图册、目标与剧情跟随实际关卡顺序；同一挑战种子仍复现相同路线。
- 强化面板展开640毫秒后才可选择；只接受新的一次鼠标点击或触屏点按，键盘和手柄不会选中强化，避免战斗输入误选。
- 新增双人在线竞速：创建房间并分享邀请链接，双方准备后同步倒数5秒，各自完成相同八境路线。可看到对方的半透明影像和关卡进度，影像不参与碰撞。
- 竞速计时包含强化选择和暂停，完成后同步双方成绩。单人远征、同图挑战与原有排行榜继续保留；在线竞速需要联网。

## v4.4.1 武器动作修正

- 法杖采用抬杖、出掌施法与回弹收势，飞轮采用独立甩投与收手动作。
- 远程武器不再复用拔刀攻击帧，并清理角色原动画中的残留剑影；待机、跑动和空中动作与当前武器对应。
- 短刃继续使用原有三连斩动作。角色、配色与像素风格保留，伤害、碰撞判定和出手时机不变。

## v4.4 战斗更新

- 七个普通关采用不同地区敌人组合和招式，角色、背景、怪物继续保持统一的像素武侠风格。

- 保留此前一跳高度、适度二段跳、天仪中枢背景修复、手机按键避碰与玉简强化界面。

## 核心玩法与强化

- 提高轻点跳跃下限：经典规则下，极短轻点约升高 150、长按约 202 逻辑像素，保留二段跳。
- 升级界面改为青玉行牒、符印和立绘式三选一，展示每项强化前后的数值。
- 九种强化提高收益，并各自呈现随本局生效的特效；HUD 显示已习得的符印和叠加层数。
- 手机移除 E 互动键；主路清理完成后，直接走入星门即可过关。

## 操作

| 动作 | 默认按键 |
| --- | --- |
| 移动 | A / D 或 ← / → |
| 跳跃、二段跳 | 空格 / K；长按跳得更高 |
| 攻击 | J / X |
| 闪避 | Shift / L |
| 格挡 | F |
| 切换武器（所有模式） | 1 / 2 / 3 |
| 释放当前旅人的觉醒 | Q |
| 进入星门 | 清理主路后走入星门；电脑也可按 E |
| 暂停、继续 | ESC / P |

手机用左侧摇杆移动、右侧按键行动，不再显示 E 按钮。按键设置与布局保存在当前浏览器。每次开始前可查看操作指南，暂停后可调整布局。

## 本地运行与离线版

需要 Node.js 20.19+ 或 22.12+。依赖版本由 `package-lock.json` 固定。

```powershell
npm ci
npm run dev
npm test
npm run build
npm run package
```

`dist/` 为网站部署文件。`delivery/星跃远征.html` 为素材内嵌的单文件，双击即可离线玩单人远征。合作远征、在线竞速及共享成绩请从网页版本进入。好友挑战可用当前页面生成链接，从离线版分享单人同图挑战时可发送 HTML 文件和挑战码。

v4.4 沿用经典版既有的共享榜单、缓存命名空间和玩家身份，不清空已有成绩。原 v4.1 八幕纪录与原四幕纪录仍独立显示，根站归档文件保留。
