# 灰烬回廊 v8 美术接入

本关从明亮卡通森林改为原创哥特像素废墟，参考《死亡细胞》的冷暖对比、成人比例、危险轮廓和环境层次，没有使用其游戏原图。使用内置 image_gen 生成，未调用 API CLI。主角保留现有完整战斗动画；本轮重做敌人和这一关的场景、交互物。

## 已接入

- 腐化木灵：枝骨身体、红色裂隙；待机、行走、瞄准、释放、收招、受击。
- 苔甲石傀：破碎石甲、沉重肩部、微亮炉芯；蓄势和冲撞姿态。
- 裂翼妖蝠：狭长骨架、破损翼膜；拍翼循环、蓄势、俯冲、恢复和受击。
- 灰烬守卫：锈蚀全身甲、暗红残披风；盾卫和精英共用该系列帧图，精英扩大并加金色标记。
- 远景：拱廊、残旗、深层修院和纠缠根系，单幅缓慢视差，无重复接缝。
- 地形：石砖、基座、腐木、铁格栅材质。保持原地图碰撞和支路通路。
- 道具：铁箍补给箱、碎裂板件、烛火石碑、血色药瓶、棘刺种子、开闭圣匣。

7 张生成母图经裁切、最近邻缩放、透明边缘处理和脚底锚点校准，产出 17 张游戏纹理。4 张敌人图条各包含 8 个关键姿态；这些是关键帧动画，尚非逐帧手绘的大型动画库。动作切换绑定实际 AI 阶段。身体判定按新轮廓校准，武器节奏、格挡、支路奖励和技能规则保留。

## 文件与复现

- 运行素材：`assets/art/ashen-cloister/`。
- 原始母图及完整最终提示词：`output/imagegen/ashen-cloister/`，其中 `generation.json` 保存每次生成的完整 prompt。
- 图条参数与哈希：运行素材目录中的 `atlas.json`、`sources.json`。
- 切帧脚本：`scripts/prepare-ashen-art.py`。优先使用项目中保留的母图，可重新产出运行纹理，不需要再次生成。
- 渲染：`assets/ashen-art.js`；`forest-art.js` 保留兼容导出名，已不加载 Pixel Adventure 卡通素材。

## 画面取舍

暗蓝、石灰、暗红为主体；金色仅用于火光、奖励和精英标记。前景站立边缘用两像素亮边区分远景建筑，背景建筑没有碰撞。木箱、石碑和圣匣保持可交互物的辨识度。落坑回返点只由点燃石碑记录。

验证沿用战斗、地图、浏览器与手机测试，另检查所有生成纹理请求成功，以及三种武器、三个种子的常规输入通关。预览摆位截图只用于检查美术，不替代这些通关验证。
