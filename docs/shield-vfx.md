# v9 重盾守卫与多帧特效

本轮使用内置 image_gen 生成，不使用 API CLI。补齐完整可见的大盾和举盾动作，替换 v8 用细色块代替盾牌的表现。敌人的正面防御、背击、重斩破架势规则保留。

## 实际帧数

| 图条 | 不同且非空的帧 | 用途 |
| --- | ---: | --- |
| shield | 16 | 4 待机、4 行走、4 举盾/挡刀、4 出剑/收招/受击 |
| slash | 24 | 玩家三连斩、敌人出剑；敌方使用预缓存暖色版本 |
| impact | 24 | 命中、重击、暴击与木箱破碎火花 |
| parry | 24 | 普通格挡、精准格挡、架势击破；大小和时长区分 |
| ember | 24 | 法杖弹体、灼印爆发和爆炸尾焰 |
| disc | 24 | 飞轮旋转循环、回程与残影 |
| dash | 24 | 闪身尾迹、敌人冲刺及火弹拖尾 |

共 144 个特效帧，另有 16 个盾卫姿态。原图中的 24 个格子沿时间变化，不是复制静态图标。`scripts/prepare-shield-vfx.py` 对实际输出逐帧做哈希与非空检查；结果记录在运行目录的 `atlas.json`。

## 绑定与播放

刀光只在有效攻击开始时产生一次，取消前摇不会留下假刀光。盾面挡刀、玩家普通格挡、精准格挡和破架势使用独立事件与尺寸。灼印爆炸绑定真实引爆，特效不延长攻击判定或产生伤害。

斩击和命中通常为 0.4 秒（24 帧、60 帧/秒），精准格挡和破架势为 0.48 秒，火焰爆发为 0.6 秒；普通格挡更短。飞轮按 48 帧/秒循环。以模拟时间推进，暂停或卡肉时冻结；最多保留 24 个事件，避免大量叠加。敌方刀光为暖色，玩家为冷色，保留敌人的预警。

旧的刀光图条、程序圆弧与普通命中图仅在新资源未就绪时回退；新资源就绪后不重复叠加。纹理和敌方配色在加载时缓存，不在每帧重新处理图片。

## 保存位置

- 运行图条：`assets/art/ashen-vfx/`，其中 `atlas.json` 包含尺寸、帧计数、非空像素计数及哈希。
- 原始生成母图、最终提示词：`output/imagegen/shield-vfx/`，完整提示词在 `generation.json`，包含格挡图透明底修正的追加提示词。
- 事件与播放逻辑：`assets/combat-vfx.js`、`assets/combat-vfx-art.js`。
- 演示脚本：`scripts/preview-combat-vfx.mjs`，为摆位实机演示，不代替无作弊通关验证。

## 验证

检查了帧图完整性、出招时机、防重复事件、取消、暂停/卡肉、事件上限、盾牌挡刀与反击规则、桌面和手机浏览器资源加载。既有三种武器、三个种子的常规输入通关检查继续保留。
