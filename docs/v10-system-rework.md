## 新主角素材

使用内置 image_gen 生成原创「余烬行者」：浅色面罩、冷蓝轻甲、暗红短披风、小圆盾，与回廊的冷色石材和敌人旧金高光统一。没有调用 CLI/API 模式。

| 图条 | 不同且非空的姿态 |
| --- | ---: |
| 跑步 | 24 |
| 待机 / 格挡 | 24（12 + 12） |
| 起跳 / 腾空 / 落地 | 24 |
| 三段刀击 | 36（每段 12） |
| 法杖 / 飞轮动作 | 24（每种 12） |
| 翻滚 | 16 |
| 受击 / 倒地 | 16（8 + 8） |

共 164 个不同姿态。`scripts/prepare-ashen-hero.py` 校验输出帧非空且哈希不重复，执行最近邻缩放和锚点整理。动画按实际移动距离、腾空、动作阶段、格挡与受击状态选择帧；多帧素材不会延长攻击判定。法杖与飞轮具有对应的发射挂点。保留现有较小的玩家身体碰撞盒，衣帽、披风和武器的视觉外延不作为完整受击区域。

母图和完整最终提示词：`output/imagegen/ashen-hero/`，`generation.json` 也记录待机腿势及跳跃透明底的修正提示词。

运行图条、帧表与哈希：`assets/art/ashen-hero/`。HUD 头像也已更换。原角色资源保留作加载失败回退。

## 试玩规则

- 普通敌人攻击造成的非致命实际损血，可形成损失量 60% 的余烬回收池；持续 2.5 秒后按每秒 0.6 颗心流失。格挡、地形伤害、木箱、空挥和无伤命中不能创造回收生命。
- 伤害命中回收量为伤害的 12%，每根攻击事件最多 0.24 颗心；不屈守势将上限提高到 0.32。爆炸多目标共享该上限。生命始终不超上限，致命受击不靠尾随特效复活。
- 连杀疾行每层 +4% 移速，最多三层，持续 8 秒；受伤后清除。
- 猎步追斩强化闪身首刀；焦痕回响延长灼印并扩大引爆；回轮刻印强化回程；不屈守势减少普通格挡成本并提高回收上限。
- 属性强化有叠加上限，打法铭刻各限一次。升级与首次点火仍回血，锻火及两处圣匣各自防重复。
- 新支路在精英区后：2460 木台 → 2630 高台 → 圣物守卫 → 铭刻圣匣。可跳过，两处支路守卫都不锁主路出口。
- HUD 生命数字以每颗心 20 生命显示，初始为 100/100；余烬回收与短暂疾行有独立提示。
